# 校園失物招領系統｜W10 協作版本 0

這是 W10 git 協作練習的起點（版本 0）。

## 常用指令
| 要做的事 | 指令 |
|---|---|
| 跑所有檢查 | `python run_checks.py` |
| 檢查 W10 進度 | `python check_w10.py` |

## 分支命名規則
`0A-r1`、`0B-r1`、`0C-r1`（第一輪），`0A-r2`、`0B-r2`、`0C-r2`（第二輪），`0A-r3`…（第三輪，加分題）。

## 規矩
- 不直接推到 main，一律開 PR。
- PR 合併時選「Create a merge commit」。
